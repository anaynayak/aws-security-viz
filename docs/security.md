# Security

In short: the tool makes read-only EC2 calls, never writes your credentials anywhere, and produces an HTML report that
makes no network requests. The reports describe your network exposure, so treat them as sensitive. The full policy
follows and is the same text as `SECURITY.md` in the repository.
